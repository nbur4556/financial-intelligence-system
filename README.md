# 📊 Financial Intelligence System (FI)

A local-first analytical engine designed to transition personal finance from "restrictive budgeting" to "business-style intelligence." 

Instead of tracking against a rigid budget, this system treats personal spending as operational expenditure (OpEx) and wealth building as capital allocation, providing high-level KPIs to drive strategic decision-making.

## 🎯 Objective
To transform raw bank transaction data into a clean, relational dataset that allows for:
- **Burn Rate Analysis:** Understanding the actual cost of existence.
- **Efficiency Ratios:** Measuring fixed costs against total income.
- **Variance Tracking:** Identifying spending anomalies against rolling averages.
- **Strategic Allocation:** Optimizing the flow of capital into investments.

## 🏗️ Architecture & Data Flow

The system follows a linear pipeline to ensure data integrity and privacy:

`Bank CSV Exports` $\rightarrow$ `etl.py (Cleaning)` $\rightarrow$ `finance.db (SQLite)` $\rightarrow$ `Jupyter Notebooks (Analysis)`

### 1. The Data Pipeline
- **Raw Exports:** CSV files from banks are placed in `/raw_exports`.
- **ETL Process:** The `etl.py` script uses regex to strip bank-specific noise (transaction IDs, store numbers, etc.) and extracts a "Clean Merchant Name."
- **Relational Mapping:** The system uses a `merchants_mapping` table. This decouples the messy raw description from the category, allowing you to re-categorize a merchant once and have it apply to all historical data.

### 2. The Chart of Accounts
Spending is categorized into four primary buckets:
- **Fixed Costs (OpEx):** The "cost of existing" (Rent, Insurance, Utilities).
- **Variable Costs (Growth/Life):** Quality-of-life levers (Dining, Travel, Entertainment).
- **Capital Allocations:** Wealth-building (Brokerage, HYSA, Retirement).
- **Debt Service:** Liability reduction (Loan payments, Interest).

## 🚀 Getting Started

### Prerequisites
- Python 3.x
- Pandas
- SQLite3

### Setup & Usage
1. **Setup Python venv**
   ```bash
   python3.x -m venv .venv
   ```
2. **Install Dependencies**
   You have been provided an install script. This will use the venv created to install dependencies from `requirements.txt`.
   ```bash
   sh install.sh
   ```

3. **Initialize Database:**
   Run the ETL script to create the SQLite database based on `schema.sql`. You have been provided a start script to use the venv.
   ```bash
   sh start.sh
   ```
4. **Import Data:**
   Place your bank CSV exports in the `/raw_exports` directory and run the ETL script: `sh start.sh`.

5. **Verify the System (Testing):**
   To ensure the ETL process and duplicate prevention are working correctly, run the automated test suite:
   ```bash
   python3 -m unittest tests/test_etl.py
   ```

6. **Categorize Merchants:**
   Check the "Unknown Merchants" list generated by the ETL script. Add these merchants and their corresponding categories to the `merchants_mapping` table in the database.

6. **Run Analysis:**
   Open the notebooks in `/notebooks` to generate KPI reports and visualizations.

## 🔐 Security & Privacy
- **Local First:** All financial data is stored in a local SQLite file (`finance.db`).
- **Git Safety:** The database and raw CSV exports are excluded from version control via `.gitignore` to prevent sensitive financial data from being committed.
